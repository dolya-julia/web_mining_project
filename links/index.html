Перечень ссылок по теме выпускной работы

В данном разделе представлены интернет-ресурсы, связанные с визуальным распознаванием речи, подготовкой видеоданных, применением методов глубокого обучения и разработкой интеллектуальных систем коммуникации. Ресурсы сгруппированы по тематическим направлениям и сопровождаются аннотациями, отражающими их значение для выполнения магистерской работы.

    1. Научные поисковые системы и электронные библиотеки

  1. Google Scholar

    Описание: Поисковая система научной литературы, предназначенная для поиска статей, диссертаций и материалов конференций по визуальному распознаванию речи и архитектурам нейронных сетей.

  2. Научная электронная библиотека eLIBRARY.RU

    Описание: Российская информационная платформа, содержащая сведения о научных публикациях и полезная для поиска отечественных исследований по компьютерному зрению.

  3. КиберЛенинка

    Описание: Научная электронная библиотека открытого доступа, предоставляющая статьи по искусственному интеллекту, обработке изображений и речевым технологиям.

  4. arXiv.org

    Описание: Открытый архив научных препринтов по компьютерным наукам и машинному обучению для ознакомления с передовыми методами обработки визуальной речи.

  5. ACL Anthology

    Описание: Библиотека публикаций по компьютерной лингвистике и речевым технологиям для изучения методов последовательностного моделирования.

    6. 2. Научные проекты и базы видеоданных

  6. GRID Audio-Visual Speech Corpus

    Описание: Англоязычный аудиовизуальный корпус данных, используемый для изучения построения моделей распознавания речи по артикуляции губ.

  7. OpenSLR (Open Speech and Language Resources)

    Описание: Платформа речевых корпусов и инструментов обработки аудио- и видеоданных для речевых технологий.

  8. Hugging Face Datasets

    Описание: Каталог наборов данных для машинного обучения, применяемый для поиска мультимодальных корпусов.

  9. RUSAVIC (описание исследования в журнале «Компьютерная оптика»)

    Описание: Материалы отечественных исследований по визуальному распознаванию русской речи и анализу ограниченного набора команд.

  10. GitHub

    Описание: Платформа для поиска открытых реализаций нейросетевых моделей, сценариев обработки видео и репозиториев по тематике Visual Speech Recognition.

  11. Papers with Code — Lip Reading

    Описание: Тематический каталог научных работ по чтению по губам, содержащий сведения о моделях, наборах данных и доступных реализациях. Полезен для поиска архитектур визуального распознавания речи и сравнения существующих исследовательских подходов.

  12. Sub-word Level Lip Reading With Visual Attention

    Описание: Страница научной работы о распознавании речи по движениям губ с использованием визуального внимания и субсловных единиц. Содержит сведения о подходе и результатах на открытых англоязычных наборах данных (LRS2, LRS3).

    13. 3. Библиотеки и инструменты машинного обучения

  13. PyTorch Documentation

    Описание: Официальная документация библиотеки глубокого обучения, используемая для реализации и тренировки архитектур нейронных сетей.

  14. PyTorch CTCLoss Documentation

    Описание: Документация функции потерь Connectionist Temporal Classification (CTC), предназначенной для обучения моделей на последовательностях, в которых временное выравнивание входных данных и целевой последовательности заранее не задано.

  15. TensorFlow Tutorials

    Описание: Практические руководства по построению моделей машинного обучения и подготовке данных.

  16. Hugging Face Transformers

    Описание: Документация по настройке моделей для обработки видео и мультимодальных данных.

  17. PyTorchVideo

    Описание: Специализированная библиотека для анализа видеоданных, временной выборки и работы с последовательностями кадров.

  18. TensorBoard

    Описание: Инструмент визуализации для отслеживания динамики функции потерь и метрик обучения моделей.

  19. Weights & Biases

    Описание: Платформа для регистрации параметров экспериментов и сопоставления конфигураций нейросетевых моделей.

    20. 4. Компьютерное зрение и обработка видеопоследовательностей

  20. OpenCV Official Website

    Описание: Базовая библиотека компьютерного зрения для обработки видеопотоков, изменения разрешений и трансформации кадров.

  21. OpenCV Documentation

    Описание: Техническое описание программного интерфейса для реализации этапов извлечения кадров.

  22. MediaPipe Face Landmarker

    Описание: Инструменты обнаружения лицевых ориентиров, применяемые для локализации области губ и нижней части лица.

  23. FFmpeg Documentation

    Описание: Утилиты командной строки для конвертации видеофайлов, нарезки фрагментов и приведения их к единому формату.

  24. Hugging Face Evaluate — Character Error Rate (CER)

    Описание: Реализация метрики Character Error Rate для оценки различий между эталонной и распознанной последовательностями символов при анализе ошибок модели.

  25. Scikit-learn Model Evaluation

    Описание: Средства расчета метрик классификации, формирования матриц ошибок и оценки результатов моделей.

  26. NumPy Documentation

    Описание: Документация по работе с многомерными массивами и тензорами для организации кадровых последовательностей.

    27. 5. Визуальная и альтернативная коммуникация

  27. International Society for Augmentative and Alternative Communication (ISAAC)

    Описание: Международная организация по развитию средств альтернативной и дополнительной коммуникации (АДК).

  28. ASHA: Augmentative and Alternative Communication

    Описание: Профессиональный портал об областях применения АДК и поддержке людей с нарушениями речи.

  29. Communication Matters

    Описание: Организация по распространению информации о технологиях помощи людям с трудностями речевого общения.

  30. AssistiveWare Learn AAC

    Описание: Информационные материалы и руководства по принципам организации общения пользователей ассистивных систем.
