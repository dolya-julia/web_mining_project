  4. A fast state reduction algorithm for incompletely specified finite state machines

    Авторы: H. Higuchi, Y. Matsunaga

    Описание: Представлен быстрый алгоритм минимизации состояний неполностью определенных конечных автоматов SLIM (SequentiaL machIne Minimizer). Описаны результаты производительности системы и экспериментальные исследования. Показано, что алгоритм SLIM позволяет существенно сократить время и используемую оперативную память.

    Источник: Higuchi H. A fast state reduction algorithm for incompletely specified finite state machines / H. Higuchi, Y. Matsunaga // 33rd Annual Conference of Design Automation. — Las Vegas, 1996. — pp. 463-466., http://www.cs.york.ac.uk ...
